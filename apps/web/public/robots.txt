# DavFlood — https://davflood.site
#
# Everything here is public safety information about Davao City, and all of it
# is welcome in search AND in AI answers. Someone asking an assistant "how
# deep does it flood in Matina" should be able to get a sourced answer, so the
# AI crawlers below are allowed on purpose rather than by omission.

User-agent: *
Allow: /

# The map's state lives in query parameters (?lng=&lat=&b=) and every
# combination renders the same page. Crawling them would multiply one URL into
# thousands of near-identical ones; the canonical tag says the same thing and
# this saves the crawl budget for the six pages that matter.
Disallow: /*?

# Served to the app, not to readers.
Disallow: /flood-news.json
Disallow: /pages.json
Disallow: /sw.js

# ---------------------------------------------------------------------------
# AI search and answer engines.
#
# Listed explicitly, not because a wildcard Allow would fail, but because the

# remove one. Blocking these does not merely stop training — it stops the
# assistant being able to CITE this site, which for a flood map is the
# difference between a Dabawenyo getting a sourced answer and a guess.
# ---------------------------------------------------------------------------
